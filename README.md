# RULESHIFT

Браузерная survival arcade на **Vite + TypeScript + Phaser 3**. Полностью client-side: без backend, API и внешних изображений, шрифтов или звуков.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://127.0.0.1:5173). Управление: WASD или стрелки. При потере фокуса раунд приостанавливается; щёлкните арену для продолжения.

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/` — готовый статический сайт. Для размещения в подкаталоге: `npm run build -- --base=./`. Отдельный lint не настроен; строгая проверка TypeScript включена в build.

## Игра

- 3 HP, 1 секунда неуязвимости после урона. 10 очков за секунду и 100 за правило без нарушений.
- KEEP MOVING: неподвижность 1.2 секунды наносит урон; движение в стену не засчитывается.
- DANGER ZONES: красные круги становятся опасными через 1.5 секунды.
- CENTER NOW: попасть целиком в безопасный круг за 4 секунды (до 3.5 на Hard).
- DODGE: уклоняться от снарядов, нацеленных на позицию игрока в момент появления.
- DON'T MOVE: 1.8 секунды на подготовку, затем 2 секунды неподвижности. HUD показывает разрешение двигаться.
- Случайные правила без повторов подряд. 1.5 секунды анонса, 4–6 секунд действия, 2.5 секунды передышки. Опасности очищаются между правилами.
- Easy / Normal / Hard переключаются через 30 и 60 секунд. Рекорд сохраняется в localStorage (`ruleshift.best`); при недоступном хранилище игра продолжает работать.

## Структура

- `src/scenes/ArenaScene.ts`: арена, игровой цикл, HUD, переходы, feedback.
- `src/player.ts`: движение, границы, HP, неуязвимость, след.
- `src/rules.ts`: пять правил, таймеры, предупреждения и hazards.
- `src/ui.ts`, `src/style.css`: меню и результаты, адаптивный интерфейс.
- `src/config.ts`, `src/storage.ts`: настройки, формат времени и рекорд.

Визуалы нарисованы средствами Phaser Graphics. Звуки можно позже подключить в местах damage, announcement и reward, не меняя систему правил.

## Ручная проверка

1. PLAY → движение обоими наборами клавиш, диагонали и границы арены.
2. Проверить все пять правил, предупреждения, урон и отсутствие старых hazards.
3. Дождаться 0 HP → PLAY AGAIN; проверить сброс HP/счёта/времени, затем MAIN MENU.
4. Перезагрузить страницу и проверить BEST SCORE.
5. Изменить размер окна; переключить вкладку и вернуться — время раунда должно остановиться до щелчка.
6. Проверить консоль браузера и production preview.
