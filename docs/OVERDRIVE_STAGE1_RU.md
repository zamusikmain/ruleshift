# RULESHIFT 2.1 — этап 1: темп и корректность целей

Дата: 2026-10-09. Только локальная feature/ruleshift-2-chaos-update. Это завершённый первый этап, а не реализация всего CHAOS OVERDRIVE.

## Диагностика

Подтверждён дефект: Blitz ограничивал active длительностью 3.25 с, но Center Now проверяет положение после 4 с (ранний tier), Color Match после 3.7 с. Они завершались с наградой без проверки. Don't Move обрывался раньше конца окна 3.8 с. Теперь минимальная длительность этих задач превышает deadline на 0.25 с, остальные события сохраняют свой timing.

Classic имел стартовую паузу 1.4 с плюс announce 1.5 с; теперь пауза .7 с. Blitz .35 → .2, Chaos .3 → .2, Survival старт .8 → .6. Последующие Survival-паузы по-прежнему задаются survivalDifficulty, без изменения его формулы. Предупреждения, скорость 265 px/s, ускорение и геометрические safety certificates не сокращены/изменены. Daily оставлен неизменным, чтобы не менять опубликованный сценарий текущей даты.

Контрольная автоматическая симуляция: seed 21, dt 1/60, 60 с, неподвижный игрок в центре, callback урона возвращает false, без реальных смертей. Это диагностический сценарий движка, не браузерный gameplay/FPS benchmark. Active включает внутренние предупреждения hazards.

| Режим | Первое active, с | Rest за 60 с | Число announce |
|---|---:|---:|---:|
| Classic | 2.20 | 4.67 | 8 |
| Survival | 1.68 | 5.05 | 9 |
| Blitz | .95 | 2.67 | 14 |
| Chaos | 1.30 | 2.12 | 11 |

Эти числа не доказывают субъективную интересность или отсутствие пустых участков внутри active. Обнаруженный пропуск deadlines доказывает конкретную проблему; остальной темп требует наблюдения реальной игры.
