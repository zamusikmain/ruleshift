# Этап 5 — текущая готовность

Этап не завершён. В этом проходе реализована только плавная регулировка джойстика 104–168 px. Она обновляет игровой джойстик и предпросмотр, сохраняется в отдельном ключе `ruleshift.joystick-pixels.v1`. Старый размер `ruleshift.controls.v1` не удаляется; кнопки Small/Medium/Large устанавливают соответствующий размер и обновляют сохранение. Пользовательское значение проверяется, округляется и ограничивается диапазоном. Выбранный preset/aria-pressed обновляется при регулировке.

Изменены `src/controlSettings.ts`, `src/ui.ts`; добавлен `tests/joystick-slider.test.mjs`. Сетевой формат остаётся v8. Daily и игровая логика в этом проходе не менялись.

Проверки: npm test 235/235, typecheck клиента/Worker/MCP успешен; финальная сборка завершилась за 4.05 с, приложение 143.28 kB / gzip 49.60 kB. Сохраняется предупреждение большого Phaser chunk. Browser QA нового ползунка, физический мультитач и FPS в этом проходе не проведены.

Не реализованы: Phase, Magnet, выбор нескольких активных способностей, Perfect Dodge, Risk Zones, Bonus Rush, Clutch Save, полный набор дополнительных эффектов. Ранее реализованные Dash/Shield/Speed/Pulse сохраняются, существующие тесты проходят.

Global Leaderboard не готов: SQL-схема и отдельная формула существуют, но passkey verification, recovery, сессии, постоянная привязка к комнате, outbox, settlement, API и реальное обновление UI отсутствуют. SQLite-тесты не подтверждают Cloudflare D1. Модель Passkeys + Recovery Codes уже согласована, повторного согласования не требуется.

До подключения Cloudflare нужно закончить локальную серверную реализацию, проверку полномочий и доставку авторитетных receipts; подготовить отдельный staging D1 binding/миграции, auth origin/RP ID и испытать это на изолированном runtime. Создание D1, удалённые миграции и rollout требуют отдельного разрешения. В этом проходе конфигурации Cloudflare не менялись, ресурсов не создавалось, deployment/commit/push/merge не выполнялись. Защищённые файлы не изменялись.

Вердикт: **NO-GO для staging этапа 5**. Запрошенный законченный геймплей и настоящий серверный рейтинг ещё не достигнуты.
