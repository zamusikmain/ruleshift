# RULESHIFT 2.0 — предрелизный QA, 2026-10-09

Ветка: `feature/ruleshift-2-chaos-update`. Проверки локальные; production, Git и Cloudflare не изменялись. Этот отчёт описывает доступное покрытие, а не подтверждает готовность всех сценариев.

## Исправления этого этапа

- Online Leave: снимок `playing`, уже находящийся в очереди до выхода, ошибочно принимался клиентом за подтверждение выхода. Экран закрывался до получения авторитетного результата forfeiture. Теперь завершение выхода по снимку требует результата; dispose сбрасывает флаг выхода. Добавлен регрессионный тест порядка сообщений.
- Offline Blitz: серверная/локальная логика лимита уже существовала, но в Offline HUD отсутствовал обратный отсчёт. Добавлен `BLITZ · mm:ss` через существующую RU/EN локализацию; проверены пауза и однократное завершение по лимиту.
- Phaser выделен в отдельный vendor-файл сборки для независимого кеширования. Общая первая загрузка практически не уменьшилась. Ленивая загрузка движка не вводилась.

## Что проверено автоматически

- Геометрия, swept collisions, предупреждения, урон, завершение и проверка безопасных путей всех восьми новых hazards.
- Шесть двойных комбинаций: Danger Zones + Laser Grid; Danger Zones + Death Spin; Laser Grid + Meteor Madness; Laser Grid + Shockwave; Death Spin + Meteor Madness; Death Spin + Shockwave.
- Две тройные комбинации: Danger Zones + Laser Grid + Meteor Madness; Danger Zones + Death Spin + Shockwave. Неподдерживаемые и небезопасные комбинации отклоняются.
- Survival и Chaos: по 30 **симулированных** минут, завершение сотен циклов и очистка состояния событий. Урон в стресс-сценарии отключён через тестовый callback для продолжения прогона; это не доказательство способности человека выжить 30 минут.
- Четыре Online-режима, каждое количество участников 2–8, по пять последовательных раундов/Rematch: всего 140 раундов модели Room. Проверены права хоста, snapshots, сброс раунда и повторная доставка результатов без двойного начисления. Результат раунда принудительно задаётся тестом для изоляции жизненного цикла.
- Существующие тесты handshake/protocol v6, отказа старым клиентам, выхода/переподключения, серверного результата, сохранений, Daily UTC/детерминированности, XP и достижений.
- Отдельные EventTarget указатели джойстика и Dash, отмена чужого/своего указателя, удаление обработчиков после destroy. Это имитация PointerEvent, а не физический мультитач.

## Что действительно выполнено в браузере

Локальная Vite production-сборка на `127.0.0.1:4173`, браузер Codex IAB:

- Создание тестового профиля, выбор и запуск Classic, Survival, Blitz, Chaos и Daily.
- Пауза, продолжение в Classic, добровольное завершение всех пяти режимов и отображение результатов. Полное успешное прохождение Daily/Blitz до 90 секунд вручную не подтверждено.
- Отдельный Classic без ввода завершился естественным поражением примерно через восемь игровых секунд; появился экран GAME OVER.
- В Classic первая активная опасность наблюдалась примерно на четвёртой секунде.
- Описание Survival/Daily, профиль и таблицы личных результатов; смена RU → EN; перезагрузка с восстановлением имени, языка и рекорда.
- 20 завершённых циклов открытия/закрытия профиля в production-сборке; после них один элемент формы имени, без ошибок консоли. Это не heap leak audit.
- Размеры 320×568 и 568×320, прокручиваемые описание Daily/результаты/профиль, отсутствие горизонтального переполнения проверенных экранов. Размер viewport не включает эмуляцию настоящего touch-устройства.
- В отдельной галерее `tests/visual.html` выбраны все восемь hazards и восемь комбинаций, выполнены кнопки предупреждения/показа фазы. Это renderer fixture, без сетевого транспорта, движения восьми реальных игроков и полного игрового цикла. Выбранное время фазы может ещё соответствовать предупреждению отдельных волн.
- Обновлённый обратный отсчёт Blitz виден в DOM готовой сборки после её перезагрузки.

| Эффекты | FPS | Максимальная задержка кадра | Кадров >50 ms | Средний вызов renderer/HUD |
|---|---:|---:|---:|---:|
| Low | 60 | 16.7 ms | 0 | 0.39 ms |
| Medium | 60 | 16.7 ms | 0 | 0.40 ms |
| High | 60 | 16.7 ms | 0 | 0.46 ms |

В этих выборках было 24 объекта сцены; приблизительный `performance.memory.usedJSHeapSize` — 22.4–33.9 MiB. Разные фазы/GC не позволяют считать эти окна строгим сравнительным benchmark. Стоимость вызова renderer не равна полной CPU/GPU нагрузке. Длительный heap profiling, реальная нагрузка CPU и показатели физического телефона не измерены.

Финальная сборка: код игры 113.00 kB (gzip 39.76 kB), Phaser 1208.06 kB (gzip 332.17 kB); суммарно JS 1321.06 kB / gzip 371.93 kB. Предупреждение Vite о файле >500 kB остаётся. Новых библиотек нет.
