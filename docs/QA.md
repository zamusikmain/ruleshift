## Что проверено

- Исходные 6 тестов поведения правил сохранены; обновлён только стенд для выделенного общего движка и визуального адаптера.
- Все 22 автоматических теста проходят: EN/RU, имя/цвет, профиль и миграция, движение/урон, очки/достижения, правила/Хаос, протокол, комната/матч/победитель/reconnect, joystick/orientation, Worker routing и WebSocket handlers.

- Визуальные проверки: desktop, 844×390 landscape и 1024×768 tablet viewport. Это НЕ проверки физических устройств.

## Блокирующая проверка Online

`npm run dev:online` не смог запустить native runtime: Windows отказал в исполнении `workerd.exe` (`spawn EPERM`, «Отказано в доступе»). Ошибка воспроизводится даже на `workerd.exe --version`.

Поэтому `npm run test:online` пока завершается `ECONNREFUSED 127.0.0.1:8787`. Автоматические тесты Worker используют тестовые WebSocket/runtime-объекты; реальный Cloudflare transport ими не подтверждается.

После устранения ограничения администратором машины:

```sh
npm ci
npm test
npm run build
npm run dev:online
```

В другом терминале:

```sh
npm run test:online
```

Не отключайте защиту системы и не используйте production deployment как замену локальной проверки.

## Multiplayer — два браузера

- [ ] Запустить локальный Wrangler, открыть `http://127.0.0.1:8787` в двух браузерах/профилях.
- [ ] Create выдаёт код; Join в другой сессии показывает обоих игроков, в том числе одинаковые имена с разными internal IDs.
- [ ] Одинаковые предпочитаемые цвета становятся различимыми в комнате, локальный профиль не меняется.
- [ ] Start доступен только хосту при 2+ готовых подключённых игроках; один участник или неготовый участник блокирует старт.
- [ ] Проверить комнаты на 2 и 8 игроков, девятый получает Room Full.
- [ ] Одинаковый countdown, rules, positions и hazards на обоих клиентах. HP и winner не принимаются из клиентских сообщений.
- [ ] Урон и elimination синхронны; выбывший видит арену и alive count, не может двигаться/влиять на матч.
- [ ] Последний выживший получает Victory; остальные — Results с именами, цветами и временем. Одновременная смерть даёт Draw.
- [ ] Rematch возвращает ту же комнату в lobby, сбрасывает готовность; новый матч восстанавливает HP и очищает hazards.
- [ ] Host Leave в lobby передаёт хоста; выход во время матча означает forfeit после явно подтверждённого Leave либо grace period при разрыве.
- [ ] Разрыв менее 8 с: best-effort reconnect в той же вкладке; больший разрыв, refresh и исчезнувшая комната дают понятную ошибку.
- [ ] Неверный код, неизвестная комната, уже начавшийся матч, malformed JSON и слишком частые сообщения не ломают сервер.
- [ ] Длительная неактивность закрывает комнату; session token не виден в broadcast snapshot.

## Баланс, требующий человеческого playtest

- Лазер: читаемость направления и достижимость бокового прохода с разных позиций.
- Hunter: достаточно ли времени на реакцию и нет ли несправедливого сближения со вторым игроком.
- Meteor Shower: overlap нескольких предупреждений, читаемость на маленьком экране.
- Shrinking Arena + Dodge: проходы, количество снарядов и урон у границы на Hard.
- Keep Moving + Hunter / Meteor Shower: комфорт на аналоговом джойстике.
- Symbol Match: максимальная дистанция до нужной зоны, читаемость I / II / III на телефонах.
- Темп игры после 60–180 секунд, ценность streak и длительность раунда Last Alive.
